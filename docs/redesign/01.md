## 1. Virada do briefing (importante)

O `REDESIGN_PLAN.md` (em `Downloads/`) mandava **preservar a identidade** (hero R3F neural, Inter, cyan/roxo/âmbar) e só elevar o motion do resto do scroll.

**O cliente (Leko) mudou a direção:** quer uma **identidade visual NOVA e impactante**, nível **Awwwards SOTD**. Pontos-chave ditos por ele:
- Identidade atual é **"genérica e futurista demais"** — mas o problema é o futurismo **clichê** (rede neural sci-fi + neon), NÃO o futuro em si. Ele quer **futurismo premium, distinto, caro**.
- **Manter a ESTRUTURA do site atual** (mesmas seções/fluxo); muda só a pele + o motion.
- Faltam: **espaço para a foto dele**, **mais conteúdo de portfólio/sobre**.
- Quer **trilha sonora** (toggle on/off, padrão Awwwards).
- Quer **muito mais movimento** e momentos de impacto.

## 2. Direção travada (provisória, validada visualmente em protótipo)

**Estética:** *Editorial Spatial-Tech* — dark navy editorial + profundidade espacial 3D + toque líquido sutilíssimo. Inspiração principal: **hubtown.co.in** (Unseen Studio, Awwwards SOTD), sabor "Spatial / 3D Depth" escolhido pelo cliente entre 3 opções (A Holographic / B Kinetic Brutalist / **C Spatial 3D ✓**).

**Stack (não violar):** framer-motion + Lenis + R3F. **SEM GSAP** (o Hubtown usa GSAP+WebGL; reproduzimos os efeitos com a stack aprovada). Next 16 / Tailwind v4 / i18n pt-BR·en·es / theming.

### Tokens extraídos do Hubtown (fonte da verdade, site vivo)
- **Fontes:** `Grotesk` (300/400/700) + `Commit Mono`. → no nosso caso: grotesco bold display + mono. Protótipo usa **Space Grotesk + IBM Plex Mono** (a fonte final do display é decisão aberta — grotesco licenciado vs. Space Grotesk).
- **Base:** `#020A18` (azul-marinho quase-preto).
- **Acento/texto:** `#D5E0FF` (branco-azulado frio). Acento periwinkle nosso: `#9DB4FF`.
- Estrutura Hubtown: canvas WebGL fixo + seções HTML transparentes; preloader 0→100% "Ready to explore"; palavras editoriais gigantes; listas numeradas; reveals mascarados.

### Paleta nossa (CSS vars do protótipo)

Princípio: monocromática fria + 1 acento periwinkle. Um acento por seção.

### Efeitos da linguagem de motion (a entregar com framer-motion/Lenis/R3F)
1. **Preloader** com contador 0→100 + barra, depois sobe e revela o hero. (framer-motion/count-up)
2. **Hero espacial 3D** — foto do Leko como plano flutuante com profundidade (translateZ), planos orbitando, parallax de **mouse + scroll**, HUD mono (coordenadas JP -7.115°/-34.861°, contador de scroll). (R3F ou CSS 3D)
3. **Água/ripple WebGL seguindo o mouse** — distorce sutilmente a grade do fundo. **DEVE SER QUASE IMPERCEPTÍVEL** (o cliente reclamou 3x de estar forte; última versão: disp 0.05, amplitude reduzida, brilhos 0.02/0.03 — ainda "dá pra melhorar"). No site real = plano shader R3F / postprocessing.
4. **Menu lateral com letras embaralhando** (text-scramble/decode) ao abrir e no hover. (JS puro)
5. **Coreografia de scroll** — reveals mascarados por linha, parallax de camadas, palavra editorial gigante deslizando, count-up dos números, cards de projeto com revelação 3D (img scale 1.3→1 + cortina + rotateY), layout assimétrico alternado.
6. **Cursor custom** com inércia + cresce nos interativos; **grain** overlay (já existem no site).
7. **Trilha sonora** com toggle Sound on/off (pad ambiente). Falta: arquivo de áudio do cliente. No protótipo foi simulado via Web Audio.
8. Tudo respeita `prefers-reduced-motion`.
